THE MODPACK ARCHIVE

Every modpack
has a story.

A Windows desktop production tool for research-backed Minecraft modpack shorts. The application organizes source evidence, creates videos and manages YouTube uploads for an authorized channel.

Evidence-first video production

Modpack quest, item and progression information is used to prepare visual stories, English descriptions and source citations. Material that is illustrative is labeled accordingly.

Controlled YouTube uploads

Uses the official YouTube Data API and Google OAuth. Automated uploads currently create private drafts only; public scheduling is disabled pending content-rights and quality review.

Creator operations

Prepares thumbnail images and informative comments, with comment-based modpack suggestions for published content when permissions and availability allow.

Current availability: This application is a locally operated development tool. It is not an open online service or public Google account connector. The website is informational and does not request Google passwords or OAuth tokens.

YouTube API integration

The application may request permission to view the authorized channel, upload videos and create comments. Permissions are used solely to operate the channel chosen by its owner. Permissions can be revoked in Google Account third-party access settings.
