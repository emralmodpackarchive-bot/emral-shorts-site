PRIVACY & DATA CONTROL

Privacy Policy

Effective date: November 7, 2026

EMRAL Shorts Studio ("the application") is currently a Windows desktop tool operated for the EMRAL Modpack Archive YouTube channel. This policy describes the application's current handling of Google and YouTube data. It does not promise availability to the public.

1. Google and YouTube APIs

The application uses the YouTube Data API Services. It authenticates with Google OAuth, and may request the following permissions when needed: youtube.readonly (read authorized channel and video information), youtube.upload (upload video drafts), and youtube.force-ssl (read and post comments and manage authorized YouTube data).

2. Information accessed or stored

For the authorized account, the application may access channel identifiers, channel titles, video metadata, video processing and visibility status, comment texts and likes necessary to select a requested modpack, and OAuth access/refresh tokens. Production work products include source footage, generated descriptions, thumbnail files, upload identifiers, processing states, verification evidence and scheduling records.

Current local recommendation records store the selected modpack, vote totals, a comment identifier and completion status rather than keeping full commenter profiles. YouTube API responses are processed transiently for these operations.

3. Purpose and data use

Data is used to confirm the owner's channel, prepare and upload approved channel content, verify whether uploads remain private, generate metadata, detect duplicate posts, publish information comments when permitted, and prioritize viewer modpack suggestions. It is not used to sell user data, build advertising profiles or provide access to unrelated third parties.

4. Storage and transmission

OAuth tokens and production records are stored locally on the operator's Windows PC. The application communicates with Google/YouTube API services to authenticate, retrieve information and submit explicitly configured channel actions. The public informational website does not collect Google passwords, OAuth tokens, viewer comments or analytics data, and does not require registration. This description does not cover standard technical logs independently handled by the website hosting provider.

5. Visibility and publishing

The current automated upload configuration creates private YouTube drafts. Public posting is disabled until content rights, quality and owner authorization requirements have been met. Publishing, updating or deleting a YouTube resource requires the relevant authorization and application setting.

6. Retention and deletion

Production records and OAuth token files are held on the operator's PC until deleted or no longer needed for operation and auditing. The operator may remove local application records and credential files through the Windows file system. You can also revoke Google authorization at any time in Google Account third-party access settings. Revoking access prevents subsequent authorized API operations, but does not automatically remove videos already uploaded to YouTube.

7. Other services and policies

The application relies on YouTube API Services and is subject to YouTube Terms of Service. Please also review the Google Privacy Policy.

8. Policy updates and inquiries

This policy will be updated if access permissions, storage, sharing, automated actions or service availability change. Contact: emralmodpackarchive@gmail.com.
